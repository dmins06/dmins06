👨‍💻 About Me

Hi, I'm Minh (DIMINN.), a third-year Data Science and AI student at the University of Transport Ho Chi Minh City (UTH), Vietnam.

I'm interested in transforming raw data into meaningful insights and building reliable, scalable data-driven systems.

My current focus:

- 📊 Data Science — Exploratory Data Analysis, Statistics, Feature Engineering and Time Series Forecasting.
- ⚙️ Data Engineering — Data Collection, ETL Pipelines, Data Cleaning, Data Validation and Database Systems.
- 🤖 Machine Learning — Predictive Modeling, Model Evaluation and Applied Machine Learning.
- ☁️ Infrastructure — Python, SQL, Linux, Docker and Cloud Technologies.

«Good data science starts with good data engineering.»
